# AI

Angular provides first-party support for AI-assisted development. Instead of relying on generic, and often outdated, model knowledge, you can give AI tools the exact context, tooling and coding standards they need to generate correct, modern Angular code.

This section covers how to set up your development environment to get the most out of AI, using officially maintained resources from the Angular team.

**Consider** integrating Angular's official AI resources into your workflow.

:::info[Why?]
Angular evolves quickly and there are often several ways to do the same thing, good and bad. Large language models are frequently trained on outdated patterns (such as NgModules, decorators for inputs/outputs or `*ngIf`) and tend to generate legacy code as a result. Official resources are kept up to date with the latest conventions (signals, standalone components, native control flow, etc.), which dramatically improves the quality and accuracy of generated code.
:::

**Avoid** blindly trusting AI-generated code.

:::info[Why?]
AI is a productivity tool, not a replacement for understanding. Always review generated code, make sure it follows the best practices described throughout this documentation and validate it with tests.
:::
